# Seal Gen

A browser-based seal and stamp **proof** studio. Pick a design, type the details, and download a PNG, JPG or PDF proof for a customer to approve.

Everything runs in the browser. Nothing is uploaded.

## Designs

- Classic round
- Double ring
- Scalloped round
- Framed stamp
- Signature block: "For Company Name" with **Director** or **Proprietor** and a blank signing space

## Options

- Show or hide stars and other symbols
- Colour filters: Original, Cool, Warm, Vivid, Muted, Mono (colour only)
- Five ink colours
- Flat proof, or the proof laid on a sample sheet ("On paper")
- Download as PNG, JPG or PDF

## Proofs only

Every export carries a **PROOF** mark and a "not for official use" caption. These files are for approving a layout before a stamp is made. Check the customer's registration papers before producing any seal.

## Use it

Open `index.html` in a browser, or host the repository with GitHub Pages (Settings, Pages, deploy from the `main` branch, root folder).

The page loads Fraunces and Inter from Google Fonts. It still works offline with system fonts.
